# 음악과 형태 변환 중심의 모션 쇼릴

## 적용 범위

브랜드의 움직임과 리듬을 보여 주는 영상에 사용한다. 모든 광고와 발표 자료에 이 스타일을 적용하지 않는다. 일정한 HUD, 특정 색 조합, 장면 수, 빠른 편집을 공통 의무로 삼지 않는다.

## 모티프와 음악

로고의 점, 글자, 모서리처럼 알아볼 수 있는 요소 하나를 골라 장면 사이에서 다른 재질이나 형태로 변형한다. 마지막에는 처음의 모티프가 브랜드나 메시지로 정리되게 한다. 명암과 화면 밀도를 변화시키되 주요 문구를 읽을 시간을 확보한다.

음악 중심 요청은 사용 가능한 음원을 먼저 고르고, 실제 박자 간격과 시작 오프셋을 확인한 뒤 장면을 배치한다. BPM 수치만으로 첫 박자가 0초라고 가정하지 않는다. 킥과 하이햇의 반 박자 차이를 듣고 검토한다. 음악이 없는 요청에는 박자 분석을 강제하지 않는다.

일정한 박자표를 작성할 때만 포함된 도구를 사용한다. `<skill>`은 이 스킬 폴더다. 출력 프레임의 끝은 제외하며, `rest`는 마지막 장면에만 쓴다.

```text
node "<skill>/scripts/beatgrid.mjs" --bpm 120 --fps 30 --length 8 --chapters "도입:4,변형:8,마무리:rest"
```

도구는 오디오를 분석하지 않고 일정한 간격의 표를 계산한다. 실제 음악의 위상과 템포 변화가 있으면 표를 조정한다. 타임라인에서 기준 시점을 하나로 유지하고, 중요한 컷이 계획한 박자에 놓이는지 확인한다.

## 제작과 검토

필요한 장면만 [2D 모션](motion.md)이나 [Blender](blender.md)로 만든다. 빠르게 움직이는 구간, 정지하는 구간, 마지막 브랜드 화면의 대비를 만든다. 프레임 드라이버는 순수한 시간 함수로 두고 난수는 시드를 고정한다.

음악 구간을 먼저 편집하고 임시 효과음 큐로 화면을 만든 뒤, 실제 동작 시점에 맞춰 최종 음향을 조정한다. [오디오](audio.md)의 합성과 음량 확인을 사용한다. 시각 타이밍을 바꾸면 관련 소리와 자막도 다시 맞춘다.

전환 직전과 직후를 연속 프레임으로 확인하고 실제 속도로 재생한다. 겹쳐 남는 레이어, 컷에서 끝나지 않는 지연 효과, 읽히지 않는 문구를 수정한다. 검증 기록은 긴 보고서 대신 결과와 수정에 필요한 근거만 남긴다.

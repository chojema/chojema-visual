# PowerPoint 시각 요소

한 장에 넣을 요소부터 기존 슬라이드 수정, 여러 장의 시각 체계까지 다룬다. 단독 도식 요청에는 전체 발표 자료나 영상 제작 절차를 적용하지 않는다. 원본을 보존하고 별도 `.pptx`에 저장한다.

## 제작 경로 선택

기존 파일의 슬라이드 크기, 테마와 마스터, 대상 슬라이드와 개체를 먼저 확인한다. 연결된 편집 도구가 있으면 지원 기능을 조회하고, 요청한 작업을 실제로 수행할 수 있는 경로를 선택한다. 이 문서의 기능 목록이 모든 도구의 지원 보장은 아니다.

| 경로 | 사용할 때 | 경계 |
| --- | --- | --- |
| Windows PowerPoint 자체 자동화(COM, PowerShell 또는 사용 가능한 Python COM 연결) | 실제 스마트아트, 도형과 그래픽 효과, 네이티브 애니메이션과 전환, PowerPoint 재생 확인 | 설치된 PowerPoint 버전과 개별 API 지원을 확인한다. Python COM 경로는 python-pptx와 별도 의존성이다. |
| 사용 가능한 PowerPoint 편집 연결 도구 | 해당 도구가 요청한 개체와 효과의 생성 또는 편집을 지원할 때 | 읽기, 생성, 수정, 재생 지원을 각각 확인한다. |
| python-pptx 등 파일 생성 도구 | 편집 가능한 기본 도형, 텍스트, 그림과 지원되는 차트를 만들 때 | 실제 스마트아트와 애니메이션, 전환을 일반 도형이나 이미지로 조용히 대체하지 않는다. 지원하지 않는 기능은 기존 견본, PowerPoint 자동화 또는 검증 가능한 XML 경로가 필요하다. |

PowerPoint 자체 자동화에서는 `Presentations.Open`으로 작업 사본을 열고 대상 슬라이드의 `Shapes`, `TimeLine`, `SlideShowTransition`을 사용한다. 사용자에게 이미 열린 문서와 세션을 보존하며, 저장 성공과 결과 파일을 확인한 뒤 이번 작업이 연 문서만 닫는다. 전용으로 생성한 애플리케이션 인스턴스만 종료한다. VBA를 실행해 제작하더라도 매크로 납품을 요청하지 않았다면 최종 파일은 일반 `.pptx`로 저장한다.

## 시각화 선택과 스타일 계승

내용의 관계를 먼저 정하고 표현을 고른다. 순서와 분기는 흐름도, 책임과 계층은 조직도, 구성 요소의 연결은 구조도나 관계도, 같은 기준의 대조는 비교표, 시점과 기간은 타임라인, 반복은 순환도로 표현한다. 수치의 비교와 추세는 실제 데이터를 가진 차트를 우선한다. 관계의 방향, 단계 순서, 계층과 단위를 임의로 바꾸지 않는다.

원본의 테마 색상, 제목과 본문 글꼴, 선 굵기, 모서리, 여백과 강조 방식을 계승한다. 가능하면 테마 색상과 글꼴 연결을 유지한다. 기존 마스터나 테마 변경이 다른 슬라이드에 영향을 주면 대상 요소의 서식만 수정한다. 새 스타일은 원본에 기준이 없거나 사용자가 재설계를 요청했을 때 정한다.

## 스마트아트와 도형

- **실제 스마트아트:** `Application.SmartArtLayouts`에서 설치 환경의 레이아웃을 찾고 `Shapes.AddSmartArt`로 만든다. 표시 이름이나 컬렉션 순번을 환경 간 고정값으로 가정하지 않는다. 선택한 레이아웃의 ID를 확인하고 `Shape.SmartArt`의 노드, 레이아웃, 색상과 스타일을 조정한다. 노드 수, 문구, 순서와 계층을 원본과 대조한다. 스마트아트 레이아웃의 자동 배치와 개별 도형의 직접 배치는 구분한다.
- **도형 기반 도식:** `Shapes.AddShape`, `AddTextbox`, `AddConnector`, 자유형 도형을 사용한다. 관계선은 `ConnectorFormat.BeginConnect`와 `EndConnect`로 실제 도형에 연결하고, 이동 후 연결 상태와 경로를 확인한다. 일반 선을 연결선처럼 보이게 놓는 것만으로 끝내지 않는다.
- **그룹과 편집:** 제목, 본문과 의미 있는 단위를 이름으로 식별하고 함께 옮길 요소를 그룹화한다. 다른 도식으로 복사할 수 있게 텍스트를 별도 편집 가능한 상태로 둔다. ID와 애니메이션 대상이 바뀔 수 있으므로 도형 병합, 재생성이나 그룹 변경은 타이밍 적용 전에 마친다.
- **도형 병합:** 필요한 경우 `ShapeRange.MergeShapes`로 결합, 교차, 빼기 등을 수행한다. 원래 개체를 보존할 사본을 만든 뒤 병합하고, 결과 개수와 서식을 확인한다. 병합 후에도 원래 도형별 편집이 가능하다고 설명하지 않는다.

사용자가 실제 스마트아트를 지정했다면 `HasSmartArt`와 노드 편집 가능성을 확인한다. 도형 기반 재현은 ‘도형 기반 도식’으로 표시한다. 지원 한계로 결과 형식을 바꿔야 하면 필수 편집 기능을 잃는 대체물을 완성본으로 처리하지 않는다.

## 그래픽과 데이터 차트

그림과 SVG 등 벡터 자산은 원본 비율, 자르기 영역과 선명도를 확인한다. 채우기, 선, 투명도, 그라데이션, 그림자, 반사나 입체 효과는 정보 위계를 돕는 범위에서 사용하고 실제 도구가 지원하는 속성만 적용한다. 로고를 변형하거나 SVG의 개별 경로까지 편집 가능하다고 가정하지 않는다. 그림을 도형으로 바꾸는 기능은 해당 환경에서 지원과 결과를 확인한 경우에만 사용한다.

차트는 제공된 데이터의 범주, 계열, 누락값과 단위를 먼저 확인한다. 원본 데이터와 레이블, 합계와 비율, 축 범위와 범례를 대조하고 출처를 기록한다. 값이 없다는 이유로 0을 임의로 넣거나 축을 잘라 차이를 과장하지 않는다. 그림 차트와 편집 가능한 네이티브 차트를 구분한다.

PowerPoint 자동화에서는 지원되는 `Shapes.AddChart2` 등의 차트 생성 기능과 `Chart.ChartData`를 사용한다. 내장 데이터와 외부 연결을 구분하고, 기본 납품은 배포 후에도 수정할 수 있는 내장 데이터로 한다. 외부 연결이 요구된 경우 경로, 갱신 방법과 연결 실패 시 동작을 확인한다. 내장 통합 문서에는 필요한 범위만 넣어 다른 시트나 숨겨진 원본 데이터가 함께 전달되지 않게 한다.

## 애니메이션과 전환

애니메이션은 한 슬라이드 안의 개체 변화이고 전환은 슬라이드 사이의 변화다. 효과가 필요 없는 정지 도식에는 추가하지 않는다. 복잡한 도식은 설명 단위로 나누고 핵심 관계가 등장 순서에도 유지되게 한다.

- `TimeLine.MainSequence.AddEffect`로 나타내기, 강조, 끝내기와 이동 경로를 지원 범위 안에서 설정한다. 효과의 대상, 순서, 클릭 시작 또는 이전 효과와 함께/다음 시작, 지연과 지속 시간을 확인한다. 개체 클릭 트리거가 필요하면 지원되는 대화형 시퀀스를 사용하고 실제 클릭으로 확인한다. 임의의 효과 번호를 추측하지 않는다.
- 스마트아트의 전체, 항목별, 계층별 애니메이션은 레이아웃과 효과에 따라 가능한 옵션이 다르다. 자동화 경로에서 옵션을 제공하지 않으면 PowerPoint의 지원되는 UI나 원본 견본을 사용하고, 개별 도형으로 변환해 스마트아트 편집 기능을 잃는 방식을 기본값으로 쓰지 않는다.
- `SlideShowTransition.EntryEffect`, `Duration`, `AdvanceOnClick`, `AdvanceOnTime`, `AdvanceTime`으로 전환과 진행 조건을 설정한다. 전환 지연과 개체 애니메이션 지연을 혼동하지 않는다. 기본은 발표자가 클릭으로 진행하도록 하고 자동 진행은 요청된 경우에 쓴다.
- 모핑처럼 버전과 개체 대응에 영향을 받는 전환은 실제 지원 환경에서만 사용한다. 앞뒤 슬라이드의 대응 개체를 유지하고 재생을 확인한다. HTML의 형태 변환을 PowerPoint 모핑으로 자동 변환할 수 있다고 설명하지 않는다.

python-pptx로 이동 경로와 회전 XML을 작성해야 할 때만 [기존 실행 예제](presentations.md#python-pptx로-만들-때)를 읽는다. 기존 `p:timing`이 있는 슬라이드에 타이밍 루트를 중복 삽입하지 않는다. 도형 ID, 타이밍 ID와 기존 효과를 확인하고 원본 효과를 보존한다. XML 구조 검사와 실제 재생 검사는 별개다.

## 배치, 접근성과 재사용

요소의 경계, 기준선과 간격을 비교해 정렬하고 슬라이드 밖 배치, 의도하지 않은 겹침, 텍스트 넘침과 잘림, 연결선 교차를 점검한다. 배경과 노드 내부의 글자처럼 의도된 겹침은 오류로 처리하지 않는다. 기존 자료의 여백과 그룹 내부 상대 위치를 보존하며, 구조를 바꾸는 대규모 재배치는 요청 범위 안에서만 수행한다. 자동 배치 뒤에는 렌더로 확인한다.

색상에만 의존하지 않고 레이블, 선 형태와 기호를 함께 쓴다. 발표 화면에서 한글 줄바꿈, 글자 크기와 대비를 확인하고, 도식의 핵심 관계를 대체 텍스트로 설명한다. 장식 요소와 의미 있는 개체를 구분하며 PowerPoint에서 읽기 순서와 접근성 검사를 확인한다. 애니메이션을 끄거나 인쇄해도 핵심 정보가 남도록 하고, 움직임이 불편한 청중을 위한 정지본은 필요할 때 제공한다.

반복해서 쓸 요소는 요청된 경우에만 견본 슬라이드나 프로젝트의 기존 자산 위치에 저장한다. 재사용 요소에는 수정할 텍스트, 데이터와 색상, 그룹 이름과 출처를 남긴다. PowerPoint 테마 연결을 유지하고, 슬라이드 크기나 다른 테마로 옮겼을 때의 배치를 확인한다. 작은 단독 작업 때문에 별도 라이브러리나 전역 견본을 만들지 않는다.

## 검증과 납품

작업한 요소와 연결된 상태만 비례해서 확인한다.

1. **저장과 구조:** 별도 경로의 `.pptx`를 다시 열고 복구 경고, 누락 개체와 외부 연결을 확인한다. 스마트아트 노드, 도형과 그룹, 차트의 데이터 편집 가능성을 해당 개체에서 확인한다.
2. **정지 화면:** 대상 슬라이드를 렌더하거나 PowerPoint에서 열어 원본과 비교한다. 문구와 데이터, 스타일, 정렬과 넘침, 한글 글꼴과 접근성을 점검한다. 관련 없는 슬라이드의 기존 내용과 효과를 보존한다.
3. **동작:** 효과를 추가하거나 바꿨을 때 대상, 시작 조건, 순서, 지연, 지속 시간, 앞뒤 전환과 최종 상태를 슬라이드 쇼로 확인한다. 클릭 트리거는 실제 조작으로 검사한다. 영상 내보내기는 자동 재생의 보조 검증이며 클릭 동작 검증을 대신하지 않는다. 기존 영상 확인 방법은 [PowerPoint로 재생 확인](presentations.md#powerpoint로-재생-확인)을 참고한다.
4. **납품:** 편집 가능한 `.pptx`를 기본으로 제공하고 수행한 검증과 남은 한계를 짧게 알린다. 정지 미리보기나 PDF는 검토 또는 인쇄가 필요할 때, 재생 영상은 요청되거나 동작 검토에 필요할 때만 추가한다. 라이선스 고지가 필요한 자산은 고지를 함께 둔다.

PowerPoint를 실행하지 못하면 파일 구조, 편집 데이터와 가능한 렌더 검사의 범위를 구분하고, 네이티브 편집과 실제 효과 재생은 미검증으로 남긴다. 다른 뷰어의 렌더 결과로 PowerPoint 재생까지 검증했다고 표현하지 않는다.
